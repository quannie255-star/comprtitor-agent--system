AgentHub — 多 AI Agent 协作平台

独立开发 | 2026.04 - 至今 | github.com/quannie255-star/AgentHub

一句话：IM 聊天式多 Agent 调度平台，用户用自然语言并行指挥多个 AI Agent（Claude Code / Codex CLI）协同完成任务。

  • 【任务拆解与路由】 自研 TaskParser 支持编号列表、逗号分隔、@-mention 三种输入模式，配合关键词匹配 + LLM 双路径路由（AgentRouter），将复杂指令的 Agent 分配准确率从 70% 提升至 90%+。支持 3 次重试 + fallback Agent 降级策略。
  • 【实时流式架构】 设计 FastAPI + SSE（Server-Sent Events）推送架构，自研异步 MessageBus（asyncio.Queue per session），实现 Agent 执行进度双阶段流式渲染（replay 历史 + live 增量），避免消息丢失。
  • 【插件化 Agent 适配】 定义 AbstractAgentAdapter 抽象基类，通过 AdapterRegistry 统一管理 Claude Code / Codex CLI 等外部 Agent 的 asyncio subprocess 生命周期，新增 Agent 类型只需实现 3 个方法。
  • 【工程交付】 293 条测试全绿，20 个 Pydantic V2 Schema 覆盖全部 API 契约，Repository 模式（aiosqlite）实现存储可替换，Docker Compose 前后端分离部署，GitHub Actions 4-job CI（test + lint + build + integration smoke test）。

AI 驱动的竞品分析 Agent 协作系统

独立开发 | 2026.04 - 至今 | github.com/quannie255-star/comprtitor-agent--system

一句话：基于 LangGraph 的 4-Agent 竞品分析流水线，自动完成"搜索采集 → 功能对比 → 报告撰写 → 质检审查"全链路，20 分钟内输出可溯源深度研报。

  • 【DAG 编排与反馈闭环】 基于 LangGraph StateGraph 构建 Collector → Analyst → Writer → Reviewer 流水线，设计 3 种 RejectReason（信源不足/ Schema 缺失/ 质量问题）的条件路由，质检驳回自动回退到对应 Agent 重跑（最多 3 轮）。同时内置顺序 fallback 模式保证 LangGraph 不可用时的系统可用性。
  • 【双轨质检机制】 Reviewer 采用"编程化规则检查 + LLM 语义审查"双轨并行：确定性规则（信源完整性、Schema 一致性、竞品名匹配）由 Python 硬编码保证判定 100% 一致；语义判断（逻辑矛盾、事实核查）由 LLM 覆盖，两者合并评分后将报告可用率从 60% 提升至 85%+。
  • 【全链路溯源体系】 设计 Evidence → AnnotatedFinding 字段级溯源模型，报告中每条结论精确绑定原始信源 URL + 摘录 + 置信度，形成"报告引用 → 参考来源 → Agent 执行轨迹 → 原始采集数据"4 层可逆向验证链路，降低业务方对 AI 黑盒的信任门槛。
  • 【可观测性基础设施】 自研 LLMTracer（调用链追踪）、CostTracker（多模型成本对比）、AuditLogger（审计日志）、Guardrails（内容安全护栏）四大可观测性组件，每次分析生成完整 trace 档案（timeline + 消息日志 + Agent 步骤 + 中间产物）。
  • 【工程规范】 130 条测试覆盖正常路径 + LLM 降级路径，支持 OpenAI / DeepSeek / Anthropic 多 LLM 统一调用层，Docker 一键部署，GitHub Actions CI/CD，ARCHITECTURE.md 含 3 个架构决策记录（ADR）。
