# 截屏指南

用 Windows 自带截图工具（Win+Shift+S）或 ScreenToGif 录制。

## 需要截的 4 张图

### 1. 输入页（assets/01-input.png）
- 启动 `python -m streamlit run src/api/routes.py`
- 浏览器打开 http://localhost:8501
- 截图：完整页面，展示输入框 + 开始按钮 + 侧边栏配置

### 2. 报告展示页（assets/02-report.png）
- 输入 "Notion" 点击开始分析
- 等流水线跑完
- 截图：滚动到报告卡片，展示前 3 个章节（目录 + 执行摘要 + 竞品概览）

### 3. 溯源面板（assets/03-trace.png）
- 在报告页底部展开"📨 消息时间线"
- 截图：展示时间线日志 + 质检评分

### 4. 终端测试（assets/04-tests.png）
- VS Code 或终端中运行 `pytest tests/ -v -q`
- 截图：最后几行显示 "128 passed"
